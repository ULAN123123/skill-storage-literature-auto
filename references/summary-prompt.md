# Paper Card 生成提示词（原样执行，不得改写）

> 本文件是 B 阶段逐篇总结使用的提示词原文。**必须原封不动执行**，不得改写、删减、简化或翻译；下面这段文字即为提示词本体。
>
> 调用 `nature-paper-card` 时，必须先加载本技能内置的完整技能文件（`nature-paper-card/SKILL.md`、`manifest.yaml`、`static/core/` 全部文件、所选 `static/fragments/paper_type/` 片段、`references/` 三份文件），在此基础上按下面的总结提示词工作。

```text
请调用 nature-paper-card，对我上传的论文进行结构化精读，并生成份中文 Paper Card。不要只翻译摘要，也不要写成笼统的论文总结。请以论文原文、图表、公式和实验结果为依据，帮助一名刚入学的研究生理解这篇论文的完整逻辑。
请先确认当前材料是否包含完整正文、图表和补充材料。如果只有摘要或部分内容，必须明确标注分析范围，不得推测未提供的内容。
请按照以下重点进行分析：
用一句话说明：这篇论文解决了什么问题、采用什么方法、得到什么有边界的结果；
解释具体研究问题，以及现有方法为什么不能充分解决；
梳理“问题一已有方法局限一核心思路一方法设计一实验验证一最终结论”的逻辑链；
用通俗语言解释整体方法流程，包括输入、输出和主要模块；
对每个核心模块说明：它有什么作用、为什么需要、去掉以后可能产生什么影响；
只保留理解论文必需的公式，并解释每个符号、公式作用和直观含义；
建立“实验一验证主张一对比对象—关键结果一支持结论”的证据表
区分作者声称的结论、实验直接支持的结论，以及不能从当前证据推出的更强结论；
单独整理作者明确承认的局限性，不要与分析者提出的批评混在一起；
提取可以迁移到其他研究中的方法、实验设计和分析思路；
基于论文局限提出可验证的研究方向，但不得末经检索就宣称具有创新性。
请生成完整的01一16节Paper Card。所有重要数字、方法判断和结论必须标明来自论文的具体章节、图、表、公式或PDF页码，无法从论文中得到数字，结论和方法不得填写。
```

## 附加执行规范：公式与上下标（B 阶段，紧接上面的提示词执行）

> 上面是提示词本体，不改动；下面是执行时必须叠加的书写规范，用于让笔记在 Zotero 里正常渲染。

1. 行内公式用 `$…$`；行间公式单独成段、用 `$$…$$` 包裹；多行推导用 `\begin{aligned}` 且整段放在 `$$` 内。
2. 上下标一律用花括号形式 `X_{sub}` / `X^{sup}`，或整段写成 `$I_V$`。禁止裸写 `I_V`、`D*_q`、`10^6`。
3. 星号用 `$A^{*}$`，不要写 `A*`（Markdown 会当强调）。
4. 标题（h1–h6）内不得出现公式；Zotero 标题不允许 math 节点。
5. 不用 KaTeX 不支持的命令：`\begin{equation}`、`\label`、`\cite`、`\bm`。
6. 只保留理解论文必需的公式（同提示词第 16 行），不要整段搬原文推导。
